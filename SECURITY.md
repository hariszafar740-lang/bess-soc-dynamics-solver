# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability (for example, unsafe deserialization or
dependency advisories), please report it privately via **GitHub Private
Vulnerability Reporting** under the repository's **Security** tab rather than
opening a public issue. Reports receive an initial response within 72 hours.
